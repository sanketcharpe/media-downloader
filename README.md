# Media Downloader

Personal Android app to save videos or audio from YouTube, Instagram, Facebook, X and
other sites supported by the open-source [yt-dlp](https://github.com/yt-dlp/yt-dlp) engine.

- Share a link to the app (or paste it), choose **Video** or **Audio only**
- Video: Best / 1080p / 720p / 480p / 360p, in MP4 or MKV
- Audio: MP3, M4A or OPUS
- Saves to `Download/MediaDownloader`
- "Update engine" keeps yt-dlp current when sites change

**Download:** see *Releases* → `MediaDownloader-arm64.apk` (for almost all phones).
For personal use and content you have the right to save.
